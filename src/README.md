# Golden Raspberry Awards — Front-end Angular

Aplicação com Dashboard e lista de filmes da categoria Pior Filme.

## Executar

Copie a pasta `src` deste pacote para um projeto Angular compatível (standalone, signals e controle de fluxo `@if`/`@for`). Na raiz do projeto, execute:

```bash
npm install
npm start
```

## Testes

```bash
npm test
```

## API

`https://challenge.outsera.tech/api/movies`

## Funcionalidades

- Dashboard: anos com múltiplos vencedores, top 3 estúdios, intervalos de produtores e busca de vencedores por ano.
- Lista: paginação no servidor e filtros de ano/vencedor.

Este pacote contém somente `src`, pois o arquivo original enviado não inclui `package.json` nem configurações da raiz.
